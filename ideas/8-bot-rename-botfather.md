# 8 · Переименовать бота через BotFather и в коде

## What

После выбора имени в [6](6-bot-naming.md):
1. Обновить имя бота в @BotFather (вручную).
2. В коде (`prompts.py` в репо `botik`) — заменить упоминания старого имени, добавить env `BOT_NAME`, использовать её в промптах вместо хардкода.
3. Обновить env в Railway.

## Why

Завершение задачи 1.5 бэклога — последнее из блока 🔴, необходимое для v1.0.

## Done when

- Имя в @BotFather соответствует выбранному в 6.
- В коде нет хардкода старого имени, всё через `BOT_NAME` из env.
- Задеплоено на Railway, бот отвечает с новым именем.
- Бэклог обновлён (пункт 1.5 → `[x]`).

## Notes

- Работа с кодом идёт в **репо `botik`** — Jarvis к нему доступа не имеет (правило Тимура).
- Обновление документации после деплоя — в `infra/registry.yaml` (обязательно по методологии проекта).
