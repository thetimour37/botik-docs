Lean Canvas — Ботик

v2.0 · концепт для согласования
Проблема
Что не работает у аудитории
  • Инсайты не удерживаются — каждый раз «как будто заново»
  • Нет ощущения роста: поговорил с ботом, и что?
  • Открытые ИИ-чаты не держат фокус — уходят куда угодно
  • Психолог дорого, редко, и «нулевой период» тратится впустую
  • Дневники не дают обратной связи и не показывают динамику
Существующие альтернативы
GPT-чаты Дневники Медитация-приложения
Решение
Что делает продукт
  • Один фокус на неделю — без переключений
  • Сбор наблюдений в моменте, не вечером по памяти
  • Ежедневное короткое резюме (5–10 мин)
  • Оценка 1–10 в начале и конце недели — видимый сдвиг
  • Каркас ACT + Колесо баланса как методология
Уникальная ценность
Первый инструмент, который не просто слушает — а показывает, что ты меняешься
Не «поговорить», а увидеть измеримый сдвиг по одной теме за неделю. Глубина копится не за счёт длинных бесед, а за счёт регулярного возвращения к одному и тому же.
Главная концепция
Один запрос → одна неделя → измеримый результат
Преимущество
Сложно скопировать
  • Накопленный контекст — уйти = потерять историю наблюдений
  • Персона Анастасия + методология ACT в одном промпте
  • Связь с живым психологом как «следующий шаг»
  • Дашборд динамики — ценность растёт со временем
Сегменты
Кто это
  • Хочет понимать себя, но устал от хаоса инсайтов
  • Был у психолога, потерял фокус между сессиями
  • Хочет привычку осознанности, но не может — нет структуры
  • Готов к регулярному формату 5–10 мин/день
Ранние последователи
  • Фан-клуб Тимура — первые ~10 человек
  • Клиенты и контакты Анастасии
Ключевые метрики
Что измеряем
  • Retention D7 / D30 (возвращается ли)
  • % недель с ≥3 наблюдениями за неделю
  • Средний сдвиг оценки 1–10 за цикл
  • Конверсия в запрос психолога
  • NPS после первого недельного цикла
Каналы
Как доберёмся
  • Фан-клуб Тимура → первый пилот
  • Клиентская база Анастасии → психологический канал
  • Сарафан: психолог рекомендует боту → бот рекомендует психологу
  • Telegram-сообщества по саморазвитию
Структура затрат
Операционные
  • Claude API (Anthropic)
  • Railway (хостинг + БД)
  • Telegram Bot API (бесплатно)
Основной ресурс
  • Время Тимура (разработка)
  • Время Насти (методология + тест)
  • Промпт-инжиниринг
Потоки выручки
v1.0 (сейчас — бесплатно)
  • Пилот на фан-клубе — без оплаты
  • Цель: проверить retention и петлю
v2.0 (монетизация)
  • Freemium → подписка (глубина + история)
  • B2B: белый лейбл для психологов
  • Реферальная модель бот ↔ психолог
