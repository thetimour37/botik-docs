# botik-docs

Бэклог, протоколы встреч и продуктовые материалы проекта **Ботик (Анастасия)**.
Код бота — в отдельном репозитории [`botik`](https://github.com/thetimour37/botik).

## Локальная структура

Клонировать рядом с репозиторием кода, чтобы Claude Code мог читать оба репо в одной сессии по относительным путям:

```
C:\Users\user\projects\botik        — код
C:\Users\user\projects\botik-docs   — этот репозиторий
```

## Содержимое

- `backlog.md` — рабочий список задач по разработке (источник истины для приоритетов)
- `meetings.md` — протоколы встреч и решения
- `how-it-works.md` — техническое описание работы бота (для не-разработчика)
- `ботик_roadmap_claude_code.md` — роадмап
- остальное — продуктовые материалы (canvas, анализ, примеры оформления и т.п.)

## История изменений

История коммитов этого репозитория не имеет значения — файлы просто обновляются на месте.
