# Ботик — Roadmap для Claude Code

Задачи выполняются **по одной**, строго по порядку.  
После каждой: проверь результат → закоммить → переходи к следующей.

Контекст проекта: Telegram-бот «Ботик» (Анастасия), Python 3.11, aiogram 3.x, Claude API, PostgreSQL (Railway). Основные файлы: `main.py`, `prompts.py`, `database.py`.

## 🔴 Блок 1 — Срочные фиксы (перед запуском фан-клуба)

---

### Задача 1.1 — Не интерпретировать молчание

**Что сделать:**  
Убери из промпта и логики любые интерпретации того, почему пользователь молчит или редко пишет. Бот не должен объяснять паузы («иногда мы отступаем не потому, что нам всё равно...» и подобное).

Вместо интерпретации — нейтральная реакция: если пользователь не отвечал 2+ дня, бот один раз спрашивает:  
> «Я заметил, что вечерние рефлексии последние несколько дней остаются без ответа — и это совершенно нормально. Мне просто интересно: этот формат вообще откликается тебе, или лучше общаться как-то иначе?»

После ответа — занести предпочтение в профиль пользователя в БД (поле `preferred_format`).  
Больше не повторять этот вопрос, если ответ уже получен.

**Файлы:** `prompts.py`, `main.py`, `database.py`

### Задача 1.2 — Итог недели только при достаточном контексте

**Что сделать:**  
Добавить проверку перед отправкой недельного итога:

- Минимум **5 дней** с момента первого сообщения пользователя
- Минимум **10 сообщений** от пользователя за период

Если условия не выполнены — не отправлять итог совсем, либо отправить короткое честное сообщение:  
> «Мы с тобой только начали — пока недостаточно разговоров, чтобы что-то подсветить. Продолжим на этой неделе.»

Если пользователь начал общение позже вторника текущей недели — первый итог пропустить полностью, начать отсчёт со следующей недели.

**Файлы:** `main.py`, `database.py`

2. Вне зависимости от ответа — даёт контакт психолога (Анастасия, контакт взять из переменной окружения `PSYCHOLOGIST_CONTACT`)

---

### Задача 2.1 — Отдельные промпты для редких ситуаций

**Что сделать:**  
Вынести из основного системного промпта редкие ситуации в отдельные файлы/функции в `prompts.py`.

Создать отдельные промпты для:
- `prompt_onboarding` — знакомство (уже сделан в задаче 1.4)
- `prompt_low_activity` — пользователь мало пишет, нужно узнать формат
- `prompt_psychologist_request` — запрос на психолога
- `prompt_session_end` — достигнут лимит сообщений (задача 3.1)
- `prompt_weekly_summary` — недельный итог

Механизм: основной промпт определяет текущую ситуацию и возвращает тег-сигнал (например `SITUATION: low_activity`). `main.py` ловит этот сигнал и на следующем шаге подгружает нужный промпт вместо основного.

**Файлы:** `prompts.py`, `main.py`

### Задача 2.2 — Банк вопросов и статистика

## 🟠 Блок 3 — Лимиты и завершение сессии

---

### Задача 3.1 — Промпт завершения сессии при достижении лимита

**Что сделать:**  
Когда пользователь достигает дневного лимита сообщений (лимит задать в `MESSAGE_LIMIT_PER_DAY` в env, дефолт = 20):

1. Бот не обрывает резко, а отправляет завершающее сообщение из `prompt_session_end`:
   > «Мы сегодня хорошо поговорили. Дам тебе время побыть с тем, что всплыло — это часть процесса. Напишу тебе, когда можно будет продолжить.»
2. После окончания таймаута (следующий день, 00:00 по часовому поясу пользователя или дефолт UTC+3) — бот пишет:
   > «Я на связи — можем продолжить, когда будешь готов. Просто напиши мне.»
3. Когда пользователь отвечает — бот формирует краткое резюме предыдущего разговора (через отдельный запрос к Claude API с промптом `prompt_resume_summary`) и предлагает 1–2 темы для продолжения.

**Файлы:** `main.py`, `prompts.py`, `database.py`

---

### Задача 3.2 — Алгоритм перехода к психологу

**Что сделать:**  
При исчерпании лимита сообщений (или по явному запросу пользователя) предложить переход к психологу. Алгоритм:

1. Бот предлагает: «Если хочется идти глубже — могу познакомить тебя с живым психологом. Хочешь узнать подробнее?»
2. Если да — уточняет: «Могу предложить психолога, с которым я связан, или помочь подготовиться к встрече со своим специалистом. Что ближе?»
3. **Если выбрана Анастасия:**
   - Спросить согласие: «Чтобы ваш разговор сразу начался с места — могу отправить Анастасии краткое резюме твоих рефлексий. Ты не против?»
   - При согласии: сформировать профиль-резюме (запрос к Claude API) и отправить Анастасии в Telegram (`PSYCHOLOGIST_TELEGRAM_ID` из env) с полями: имя/ник, дата старта, кол-во дней, кол-во сообщений, ключевые темы, профиль на языке психолога
   - Пользователю отправить контакт Анастасии и подтверждение
4. **Если свой специалист:**
   - Предложить сформировать резюме для себя: отправить пользователю текстом прямо в чат

**Файлы:** `main.py`, `prompts.py`, `database.py`
