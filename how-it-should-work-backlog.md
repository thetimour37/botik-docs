- [x] **1.1 Не интерпретировать молчание**  
  Если пользователь молчал в течение дня (нет сообщений более 1 дня) — бот **один раз** задаёт вопрос:  
  _«Я заметил, что вечерние рефлексии последние несколько дней остаются без ответа — и это совершенно нормально. Мне просто интересно: этот формат вообще откликается, или лучше общаться как-то иначе?»_  
  Фиксируется время вопроса (`silence_question_asked_at`). После этого включается **режим редких напоминаний** (`silence_mode = 'rare_reminders'`):  
  — Каждые 2 дня в 9:00 (GMT+3) бот присылает: _«Добрый вечер. Есть желание продолжить рефлексию?»_  
  — После 3 таких напоминаний включается **режим паузы** (`silence_mode = 'pause'`) — бот больше не пишет первым.  
  — Любое сообщение от пользователя в любом режиме → сброс в нормальный режим (`silence_mode = 'normal'`).  
  В режимах `rare_reminders` и `pause` вечерняя рефлексия не запускается.  
  Новые поля в БД: `silence_question_asked_at`, `silence_mode`, `silence_reminder_count`, `silence_last_reminder_at`.  
  `main.py` · `database.py`

- [x] **1.2 Итог недели только при достаточном контексте**  
  Проверка применяется только для **первого** недельного итога (нет ни одного сохранённого weekly_summary).  
  Если сообщений от пользователя **менее 30** — отправить:  
  _«Мы с тобой только начали — пока недостаточно разговоров, чтобы что-то подсветить. Продолжим на этой неделе.»_  
  Если **30 и более** — по стандартной схеме.  
  Для последующих недельных итогов — всегда стандартная схема.  
  **Ежедневная рефлексия**: первый раз запускается только если у пользователя **более 10 сообщений** за всё время. Если меньше — пропустить молча.

## 🟠 Блок 3 — Лимиты и завершение сессии

- [ ] **3.1 Плавное завершение сессии при достижении лимита**  
  Лимит сообщений в день: переменная окружения `MESSAGE_LIMIT_PER_DAY` (дефолт = 20).  
  При достижении лимита бот отправляет сообщение из `prompt_session_end`:  
  _«Мы сегодня хорошо поговорили. Дам тебе время побыть с тем, что всплыло — это часть процесса. Напишу тебе, когда можно будет продолжить.»_  
  После таймаута (следующий день 00:00, дефолт UTC+3) — бот пишет:  
  _«Я на связи — можем продолжить, когда будешь готов. Просто напиши мне.»_  
  Когда пользователь отвечает — бот формирует резюме предыдущего разговора (`prompt_resume_summary`) и предлагает 1–2 темы для продолжения.  
  `main.py` · `prompts.py` · `database.py`

- [ ] **3.2 Алгоритм перехода к психологу**  
  Запускается при исчерпании лимита или по явному запросу пользователя.  
  Алгоритм:  
  1. _«Если хочется идти глубже — могу познакомить тебя с живым психологом. Хочешь узнать подробнее?»_  
  2. Уточнить: _«Могу предложить психолога, с которым я связан, или помочь подготовиться к встрече со своим специалистом. Что ближе?»_  
  3. Если выбрана Анастасия → спросить согласие на отправку резюме → при согласии отправить Анастасии (`PSYCHOLOGIST_TELEGRAM_ID`) сообщение с полями: имя/ник, дата старта, кол-во дней, кол-во сообщений, ключевые темы, профиль на языке психолога. Пользователю — контакт и подтверждение.  
  4. Если свой специалист → сформировать резюме и отправить пользователю текстом в чат.  
  `main.py` · `prompts.py` · `database.py`

## 🔵 Блок 4 — Развитие функционала

- [ ] **4.1 Психообразование в диалоге**  

  > ⚠️ Реализовывать в коде пока не нужно. Задача находится в стадии проектирования.

  **Цель:**  
  Постепенно обучать пользователя ключевым концепциям психологии — прямо в ходе диалога. Это делает общение с ботом более осознанным, а в перспективе облегчает работу с живым психологом.

  **Принцип отбора тем — профильное соответствие:**  
  Тема вставки выбирается не случайно и не по порядку, а на основе **профиля пользователя и текущего разговора**. Claude анализирует, какие концепции наиболее резонируют с тем, что человек проживает прямо сейчас. Например, если в разговоре звучит самокритика — приоритет получает тема «внутренний критик»; если описывается конфликт с близким — «треугольник Карпмана». Темы, которые уже были отправлены, получают пониженный приоритет.

  **Банк тем (20 концепций):**  
  1. Треугольник Карпмана  
  2. Когнитивные искажения (общее)  
  3. Катастрофизация  
  4. Чёрно-белое мышление  
  5. Внутренний критик  
  6. Окно толерантности  
  7. Реакция «бей / беги / замри»  
  8. Осознанность (mindfulness)  
  9. Принятие вместо контроля  
  10. Ценности как компас  
  11. Эмоциональная регуляция  
  12. Защитные механизмы  
  13. Проекция  
  14. Границы личности  
  15. Транзактный анализ: Родитель / Взрослый / Ребёнок  
  16. Нарратив о себе  
  17. Соматические сигналы (тело как индикатор)  
  18. Резилентность  
  19. Персонализация  
  20. Сепарация и автономия  

  **Логика включения:**  
  — Каждые `EDU_FREQUENCY` сообщений от пользователя (константа в `config.py`, дефолт = 15)  
  — Только в фазе `active` (не во время онбординга)  
  — Claude получает: профиль пользователя + текущий разговор + список уже отправленных тем → сам выбирает наиболее уместную тему и формулирует вставку  
  — Вставка добавляется в конце обычного ответа, отделяется визуально (`—`), 2–3 предложения  

  **Формат вставки:**  
  > *— По ходу нашего разговора хочу поделиться одним наблюдением. То, что вы описываете, очень похоже на «катастрофизацию» — когда мозг автоматически выбирает худший сценарий из возможных. Замечать этот момент — уже половина работы.*

  **База данных — таблица `edu_log`:**  
  ```
  id        SERIAL PRIMARY KEY
  user_id   BIGINT
  topic     TEXT        — название темы из банка
  sent_at   TEXT        — ISO datetime UTC
  ```  
  Одна запись = одна отправка. Сколько раз тема отправлялась — считается через `COUNT` по `(user_id, topic)`.

  **Функции в `database.py`:**  
  — `log_edu_insert(user_id, topic)` — записать факт отправки  
  — `get_edu_sent(user_id)` → `dict[topic, count]` — сколько раз каждая тема отправлялась  

  **Промпт в `prompts.py`:**  
  `EDU_INSERT_PROMPT` — получает профиль, последние сообщения, список уже отправленных тем и их частоту. Возвращает JSON: `{"topic": "...", "text": "..."}`.

  **Файлы:** `prompts.py` · `main.py` · `database.py` · `config.py`
