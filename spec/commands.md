# Команды бота

**Кратко (TL;DR).** Пользовательские команды режима 2, таблица «команда × состояние», служебные команды администраторов, скрытые и устаревшие команды, меню команд Telegram. Статусы реализации не ведутся в спеке (источник — задачи Linear). Режимы: режим 2 («осознанная рефлексия») — основной; режим 1 — старая логика (legacy).

## Пользовательские команды

| ID | Команда | Что делает | Блок |
|---|---|---|---|
| CMD-SETTINGS | `/settings` | Просмотр и редактирование контракта (время вечера); фокус здесь не меняется | [Блок 1](blocks/1-contract.md) |
| CMD-FOCUS | `/focus` | Текущий запрос (с последней оценкой 1–10) и фокус наблюдения (оценки по фокусу нет); смена фокуса в любой день кнопками «Предложи варианты» / «Свой фокус» — единственный путь смены | [Блок 3](blocks/3-daily.md) |
| CMD-DASHBOARD | `/dashboard` | Дашборд: динамика оценки запроса, регулярность и объём, текущий запрос и фокус; кнопка «Сменить фокус» ведёт в `/focus`. Форма (команда, мини-приложение Telegram или HTML) не решена | Блоки 6–7 |
| CMD-PAUSE | `/pause` | Поставить анализ на паузу вручную: то же состояние `paused`, что кнопка «Мне бы паузу», с тем же признающим текстом Насти; выход — любое сообщение пользователя | Блок 5 |
| CMD-SESSION | `/session` | Запустить еженедельную сессию с психологом Анастасией, если она ещё не использована на этой неделе (название рабочее) | Блок 6 |
| CMD-SUPPORT | `/support` | Благодарность, поддержка проекта | — |

## Служебные команды (только администраторы)

| Команда | Что делает |
|---|---|
| `/debug` | Версия бота с коммитом и ссылкой на страницу релизов на GitHub; глобальный режим: `1 — свободное общение` / `2 — регулярная рефлексия`. При перезапуске бота с новой версией админам приходит отчёт с блоком «Что изменилось» — release note из `release_notes/vX.Y.Z.md` репозитория бота |
| `/setmode2all` | Установить режим 2 у всех пользователей (название рабочее) |
| `/profile`, `/profileupdate` | Профиль пользователя и его обновление; только для администраторов: профиль остаётся фоном для нейронки |
| `/resetonboarding` | Сброс онбординга |
| `/resetv2 [id …]` | Сброс выбранных пользователей в «первый вход» режима 2 |
| `/resetv2 all` | Массовый перевод всех пользователей режима 1 (`flow_version=1`) на режим 2 |
| `/simulate`, `/simulateday`, `/simulateweek`, `/simulatemonth`, `/simulateyear` | Симуляции для тестирования |
| `/stats` | Статистика: пользователи, сообщения, лимит дня, даты |

## Скрытые и устаревшие

| Команда | Состояние |
|---|---|
| `/progress` | Прогресс рефлексий за последние 10 дней. Только режим 1; в режиме 2 скрыта, регулярность и объём — в `/dashboard` ([решение](decisions/2026-10-14-progress-hidden-mode2.md)) |

## Меню команд Telegram

- Пока часть пользователей на старой логике (режим 1), меню разное. Меню по умолчанию — старое: `/rules`, `/help`, `/support`.
- Пользователям режима 2 — своё меню на их чат: `/focus`, `/dashboard`, `/session`, `/pause`, `/settings`, `/rules`, `/help`, `/support`. Ставится при запуске бота, при `/start` и при сбросе.
- Если в базе не осталось пользователей режима 1, меню режима 2 становится меню по умолчанию (его видят и новые пользователи до `/start`). Пока такие пользователи есть — по умолчанию старое. Пользователям в служебном режиме 1 при меню режима 2 по умолчанию ставится старое меню на их чат.
- Меню пересчитывается при запуске бота и после `/resetv2 all`. Команды и описания берутся из кода (`services/menu.py`); в BotFather вручную ничего менять не нужно.
