# Ботик. Схема общения с пользователем

*Полный путь: от первого «Привет» до месячного среза.*

> **Это обзорная схема, а не источник текстов.** Источник истины: [`спецификация_взаимодействия_v1.md`](спецификация_взаимодействия_v1.md). Заменяет `схема_общения_v1.html` (обновлено 2026-10-13, BOT-23). Подробности каждого блока и тексты Насти смотри в спецификации; старт пользователя — в [`схема_старта_v1.md`](схема_старта_v1.md).

## Неделя пользователя

| День | Время | Что делает бот |
|---|---|---|
| Пн–пт | 9:00 | Утреннее сообщение (один из 5 вариантов Насти по дню недели), если пользователь ещё ничего не писал |
| Пн–пт | в течение дня | Реагирует на наблюдения: первые 3 сообщения дня текстом, дальше эмодзи 👍 (с проверкой на кризис) |
| Пн–пт | время из контракта (по умолчанию 20:00) | Вечер: обучающий вопрос → резюме дня; если дня не было — вопрос-приглашение, ждёт до 23:30, затем закрывающее сообщение |
| Пн | время из контракта | Резюме включает накопленное за выходные |
| Сб | 9:00 | Недельное резюме + оценка 1–10 + выбор «Продолжить тему» / «Новый запрос» + приглашение на сессию с психологом |
| Сб, вс | — | Бот сам не пишет. На наблюдения пользователя реагирует как обычно, вечернего резюме нет |
| Первая сб месяца | 9:00 | Месячный срез вместо недельного резюме |

## Блоки

| Блок | Название | Суть | Описание |
|---|---|---|---|
| 0 | Онбординг | Экраны 0.1 и 0.2, один раз | Спецификация, Блок 0 |
| 1 | Контракт | Один вопрос: время вечернего резюме | Спецификация, Блок 1 |
| 2 | Определение фокуса | Готовые вопросы → психолог при затруднении → кнопки подтверждения → оценка 1–10 | Спецификация, Блок 2 |
| 3 | Ежедневный сбор | Утреннее сообщение, реакции на сообщения, особые случаи | Спецификация, Блок 3 |

| 6 | Недельный цикл | Суббота 9:00, дашборд, сессия с психологом | Спецификация, Блок 6 |

## Особые случаи (Блок 3)

- **Просьба о помощи / срочное** → выход из режима приёма, короткий диалог, мягкий возврат к формату.
- **Уход на другую тему** → бот признаёт и предлагает запомнить как тему на следующую неделю.
- **Тяжёлый сигнал / кризис** 🔴 → выход из приёма, признание, контакт Насти или кризисной службы, тема недели ставится на паузу (алгоритм на согласовании с Настей).

## Молчание (Блок 5)

| Будних дней без сообщений | Что делает бот |
|---|---|
| 1–2 | Ничего особенного, вечер как обычно |
| 3 | Сообщение-заготовка Насти с кнопками «Продолжаю рефлексию» / «Мне бы паузу» |
| Нет ответа | Пауза до конца недели, недельное резюме в субботу |
