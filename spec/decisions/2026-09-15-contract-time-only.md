# Решение: контракт содержит только выбор времени вечернего резюме

**Что решили.** В контракте остаётся один вопрос — время вечернего резюме ([B1-01](../blocks/1-contract.md), [B1-10](../blocks/1-contract.md)).

**Что было раньше.** В контракте были вопросы про напоминания и про молчание 3+ дня.

**Почему так.** Сами функции (напоминания в течение дня, реакция на 3-дневное молчание) из продукта не убраны: они работают по поведению по умолчанию без выбора на старте ([B1-05](../blocks/1-contract.md), [B1-06](../blocks/1-contract.md)). Согласовано с Настей.
