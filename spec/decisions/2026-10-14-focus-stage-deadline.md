# Решение: Срок «до конца дня, но не меньше 3 часов» для запроса и оценки

**Что решили.** Срок действует и для этапа запроса и оценки: отсчёт от вопроса о запросе; на этапе фокуса отсчёт заново от его начала. Не назвал запрос до срока — запрос по умолчанию ставится вместе с фокусом по умолчанию (с комментарием к запросу по умолчанию).

**Что было раньше.** Срок был описан только для диалога фокуса; когда ставится запрос по умолчанию — оставалось открытым.
