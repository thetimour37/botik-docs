# Решение: Смена фокуса — один путь, `/focus`

**Что решили.** Фокус меняется одним путём — `/focus`, кнопками «Предложи варианты» и «Свой фокус»; `/dashboard` ведёт туда же; `/settings` — только контракт; запрос при смене не меняется. Детали реализации (допущение, подтвердить): варианты — нейронка по наблюдениям последних 7 дней (учитывает запомненные «другие темы»), под вариантами кнопка «Оставить текущий»; у «Своего фокуса» кнопки «Да, этот фокус» / «Сформулирую иначе» / «Оставить текущий», фразу и подтверждение ждём не дольше [P-FOCUS-CHANGE-OWN-MAX-HOURS](../parameters.md#ежедневный-сбор-и-фокус-блоки-23); пока идёт субботний выбор фокуса, `/focus` только показывает запрос и фокус и отсылает к кнопкам субботы; новый фокус действует сразу.

**Что было раньше.** Смена фокуса была раздроблена: настройки, дашборд, суббота.

**Почему так.** Решение Тимура 2026-10-14: единый понятный путь.
