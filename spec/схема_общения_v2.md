# Ботик. Схема общения с пользователем

*Полный путь: от первого «Привет» до месячного среза.*

> **Это обзорная схема, а не источник текстов.** Источник истины: [`спецификация_взаимодействия_v2.md`](спецификация_взаимодействия_v2.md). Заменяет `схема_общения_v1.html` (обновлено 2026-10-13, BOT-23). Подробности каждого блока и тексты Насти смотри в спецификации; старт пользователя — в [`схема_старта_v2.md`](схема_старта_v2.md).

## Неделя пользователя

| День | Время | Что делает бот |
|---|---|---|
| Пн–пт | 9:00 | Утреннее сообщение (один из 5 вариантов Насти по порядку отправки: первое — вариант 1, дальше по очереди, сброс в субботу), если пользователь ещё ничего не писал и состояние `active` |
| Пн–пт | в течение дня | Реагирует на наблюдения: первые 3 сообщения дня текстом, дальше эмодзи 👍 (с проверкой на кризис) |
| Пн–пт | время из контракта (по умолчанию 20:00) | Вечер: обучающий вопрос → резюме дня; если дня не было — вопрос-приглашение, ждёт 30 минут, затем закрывающее сообщение. После резюме — снова сбор наблюдений к следующему резюме |
| Пн | время из контракта | Резюме включает накопленное за выходные |
| Сб | 9:00 | Недельное резюме (текст + график регулярности, звёздочки) → сообщение про выходные с кнопкой «Изучил, готов продолжить» → «Что влияло?» с выбором фокуса (3 варианта / оставить текущий / свой) → приглашение на сессию «Сейчас» / «Позже». Новичку с менее чем 3 будними днями — короткое сообщение вместо резюме |
| Сб, вс | — | Бот сам не пишет. На наблюдения пользователя реагирует как обычно, вечернего резюме нет |
| Первая сб месяца | 9:00 | Месячный срез вместо недельного: отчёт за месяц → оценка запроса 1–10 и «было X, стало Y» → продолжить запрос / взять новый → дальше как в обычную субботу. Если со старта прошло 10 дней или меньше — обычное недельное резюме и сообщение «отчёт начнёт приходить со следующего месяца» |

## Блоки

| Блок | Название | Суть | Описание |
|---|---|---|---|
| 0 | Онбординг | Экраны 0.1 и 0.2, один раз | Спецификация, Блок 0 |
| 1 | Контракт | Один вопрос: время вечернего резюме | Спецификация, Блок 1 |
| 2 | Запрос и фокус | Запрос (по желанию) → оценка запроса 1–10 → готовые вопросы Насти и при затруднении диалог с психологом → варианты фокуса, выбор одного | Спецификация, Блок 2 |
| 3 | Ежедневный сбор | Утреннее сообщение, реакции на сообщения, особые случаи | Спецификация, Блок 3 |
| 4 | Вечер | Обучающий вопрос, резюме дня, пустой день, закрытие | Спецификация, Блок 4 |
| 5 | Молчание и пауза | 3 будних дня тишины → кнопки «Продолжаю» / «Мне бы паузу» | Спецификация, Блок 5 |
| 6 | Недельный цикл | Суббота 9:00, дашборд, сессия с психологом | Спецификация, Блок 6 |
| 7 | Месячный срез | Первая суббота месяца: оценка запроса, динамика, смена запроса | Спецификация, Блок 7 |

## Особые случаи (Блок 3)

- **Просьба о помощи / срочное без кризисных маркеров** → бот в диалог не переходит; напоминает, что по субботам после недельного отчёта есть часовая сессия, а если сессия этой недели не использована — предлагает запустить её сейчас (кнопка). Текст генерирует нейронка.
- **Уход на другую тему** → бот признаёт и предлагает запомнить как тему на следующую неделю.
- **Кризис (красный / оранжевый / жёлтый уровень)** → готовый текст Насти по уровню (телефоны помощи), затем возврат к обычному сбору; фокус не снимается, бот ждёт сообщения пользователя. Проверка — на каждом сообщении во всех режимах. В сессии — сессия прерывается и считается использованной.

## Молчание (Блок 5)

| Будних дней без сообщений | Что делает бот |
|---|---|
| 1–2 | Ничего особенного, вечер как обычно |
| 3 | В вечернее время вместо приглашения — сообщение-заготовка Насти с кнопками «Продолжаю рефлексию» / «Мне бы паузу» (проверка №1) |
| Ещё 3 и 6 будних дней без ответа | Проверки №2 и №3; после третьей — полная тишина (`dormant`) до сообщения пользователя. В `checking` недельное резюме приходит, если есть наблюдения |

## Команды

Для пользователей новой логики (меню команд): `/focus`, `/dashboard`, `/session`, `/pause`, `/settings`, `/rules`, `/help` (в конце — версия бота), `/support`. `/progress` — только в старой логике (режим 1). Служебные для администраторов: `/debug` (версия бота и ссылка на релизы), `/profile`, `/profileupdate`, `/resetv2`, `/simulate*` и другие. Полный список со статусами — в спецификации, раздел «Команды бота».
