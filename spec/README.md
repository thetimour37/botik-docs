# Спецификация поведения бота

> ⚠️ **Концепция продукта была пересмотрена в августе 2026 года** (с нуля, после 4-месячной паузы). Файлы в этой папке отражают **новую** концепцию. Корневые `how-it-should-work-backlog.md`, `roadmap.md` и `how-it-works-now.md` пока отражают **старую** (апрельскую 2026) концепцию — блок 🔴 (срочные фиксы) в бэклоге остаётся в силе, остальное требует пересмотра под новую концепцию. Не считать их приоритетами, пока не согласованы с материалами ниже.

Два человека в команде: Тимур (разработка), Анастасия (методология, тестирование). Стек: Python 3.11, aiogram 3.x, Claude API, PostgreSQL, Railway.

## Файлы новой концепции (по порядку чтения)

1. **`конспект_встречи_пересмотр_концепции.md`** (в `../meetings/`) — главный документ для понимания сдвига концепции: предпосылки пересмотра, новые принципы и цели, полный алгоритм работы по шагам (этапы A–F), таблица из 9 существенных расхождений со старой концепцией, открытые вопросы и идеи в бэклог.
2. **`анализ_новой_концепции.md`** — экспертная оценка новой концепции: сильные стороны, риски, критическая развилка по методологической базе (почему Human Design не подходит), рекомендации до сборки.
3. **`концепт_продукта_v2.md`** — двухчастный документ: часть I — описание продукта для внешней аудитории, часть II — список из 8 пунктов для согласования с Анастасией, от фундаментального к деталям.
4. **`методологический_каркас_v1.md`** — методологическая основа классификации пользовательских запросов. Слой 1: Колесо баланса (8 сфер жизни). Слой 2: Ценности ACT (10 направлений). Механика классификации с примером. Список из 5 пунктов для согласования с Анастасией.
5. **`спецификация_взаимодействия_v1.md`** — полная спецификация логики работы бота с пользователем, основной технический документ для разработки. 7 блоков: контракт, выявление запроса, ежедневный сбор, вечернее резюме, напоминания и молчание, недельный цикл, месячный срез. Включает таблицу команд бота и три открытых задачи для Анастасии (помечены 🔴).
6. **`lean_canvas_botik_v2.md`** (в `../product/`) — Lean Canvas продукта, все 9 блоков, актуальная версия с учётом новой концепции.
