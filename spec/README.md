# Спецификация поведения бота

> ⚠️ **Концепция продукта была пересмотрена в августе 2026 года** (с нуля, после 4-месячной паузы). Файлы в этой папке отражают **новую** концепцию. Файлы `old/how-it-should-work-backlog.md`, `old/roadmap.md` и `old/how-it-works-now.md` (перенесены в архив 2026-10-13) отражают **старую** (апрельскую 2026) концепцию. Не считать их источником правды и приоритетов.

Два человека в команде: Тимур (разработка), Анастасия (методология, тестирование). Стек: Python 3.11, aiogram 3.x, Claude API, PostgreSQL, Railway.

## Файлы новой концепции (по порядку чтения)

1. **`конспект_встречи_пересмотр_концепции.md`** (в `../meetings/`) — главный документ для понимания сдвига концепции: предпосылки пересмотра, новые принципы и цели, полный алгоритм работы по шагам (этапы A–F), таблица из 9 существенных расхождений со старой концепцией, открытые вопросы и идеи в бэклог.
2. **`анализ_новой_концепции.md`** — экспертная оценка новой концепции: сильные стороны, риски, критическая развилка по методологической базе (почему Human Design не подходит), рекомендации до сборки.
3. **`концепт_продукта_v2.md`** — двухчастный документ: часть I — описание продукта для внешней аудитории, часть II — список из 8 пунктов для согласования с Анастасией, от фундаментального к деталям.
4. **`методологический_каркас_v2.md`** — методологическая основа классификации пользовательских запросов. Слой 1: Колесо баланса (8 сфер жизни). Слой 2: Ценности ACT (10 направлений). Механика классификации с примером. Список из 5 пунктов для согласования с Анастасией.
5. **`спецификация_взаимодействия_v2.md`** — **единственный источник истины** по поведению бота, основной технический документ для разработки (обновлено 2026-10-13, BOT-23). Блоки: онбординг, контракт, определение фокуса, ежедневный сбор (с утренним сообщением), вечер, молчание и пауза, недельный цикл (с сессией психолога), месячный срез. Включает таблицу команд со статусами, таблицу расхождений с кодом и открытые задачи для Анастасии (помечены 🔴). В неё влита `схема_дня_v2.md` (перенесена в `../old/spec/`).
   - **`схема_старта_v2.md`**, **`схема_общения_v2.md`** — обзорные схемы (заменили одноимённые HTML). Тексты не дублируют, ссылаются на спецификацию.
6. **`lean_canvas_botik_v2.md`** (в `../product/`) — Lean Canvas продукта, все 9 блоков, актуальная версия с учётом новой концепции.
