#проектботик #фокус #план 


**Как выглядит продукт к концу месяца**

- функционирует на постоянной основе (контроль доступа)
- ведет диалог с пользователями регулярно, но не навязчиво.
- полностью сформированная стартовая велком страница использования, понятная и очевидная 
- реализован функционал по версии v2 в режиме ежедневних резюме рефлексий

- шифрует данные для конфиденциальности
- оцифровывает прогресс пользователя (выводит данные регулярно)
- оптимизирован для использования токенов


**Кто пользуется**
- фан клуб людей, которые положительно настроены, дают обратную связь, помогают развивать


**В каком объёме**
- 50 пользователей


**Как выглядит процесс разработки**

- есть чат jarvis Ботик, в котором ведется общение я и Настя и jarvis по составлению образа продукта, ближайших задач, реализованных функций, статистика использования ботика, обратная связь пользователей и их учет.
- данный jarvis как основа для продвижения ботика в соцсетях и автоматизация задач по его сопровождению

**Как выглядит процесс запуска и продвижения**

Есть план запуска со списком задач, синхронизованный с разработкой кода.
