# v2.1.0 — версия бота и описание релизов

Теперь видно, какая версия бота работает, и что в ней изменилось по сравнению с предыдущей.

## Что нового

- **Версия в `/help`.** В конце списка команд показывается номер версии бота.
- **Версия и ссылка в `/debug`** (для администраторов). Номер версии, короткий номер сборки и ссылка на страницу релизов на GitHub, где описано, что нового в каждой версии.
- **Описание релиза в отчёте о запуске** (для администраторов). Когда бот перезапускается с новой версией, сообщение о запуске дополняется блоком «Что изменилось»: «было → стало» по версиям и описание простым языком. При обычном перезапуске без новой версии блока нет.

## Для существующих пользователей

Ничего не меняется. Версию бота видно в `/help`, остальное только для администраторов.

## Известные ограничения

- Номер версии задаётся в коде и меняется при каждом релизе вручную вместе с описанием релиза.
- Остальное — как в v2.0.0: часть текстов пока формирует нейронка вместо авторских текстов Насти (BOT-45), время везде GMT+3.
