# v2.4.0 — удалена административная команда /setmode2all

## Что исправлено

- **Удалена административная команда `/setmode2all`.** Команда переводила всех пользователей на режим 2 (регулярную рефлексию) и была нужна для разового массового перевода. После успешного переключения всех пользователей команда больше не используется и убрана из бота, из подсказок `/debug` и из списка команд.

## Для существующих пользователей

Ничего делать не нужно. Эта команда была видна только администраторам и не влияла на обычных пользователей.

## Известные ограничения

Нет.
