# 19 · Реализовать этап приветствия

## What

Когда пользователь впервые подключается к боту (первый `/start`) — показать **два экрана онбординга** до Блока 1 (Контракт):

1. **Экран 0.1 · Приветствие** — короткий текст «Это пространство для регулярной рефлексии…» + кнопка `Начать`.
2. **Экран 0.2 · Инструкция «как это работает»** — подробное описание формата (7 шагов + «что важно знать») + переход к контракту.

Тексты обоих экранов уже написаны Настей — см. `botik-docs/meetings/2026-09-11-заметки-насти-по-схеме.md`, разделы «Экран 0.1» и «Экран 0.2».

## Why

Приоритет 0: сейчас у бота нет онбординга, пользователь сразу попадает в контракт без объяснения куда попал. Настя проработала тексты. Это первое живое изменение в продакшн-бот из утреннего ритуала 2026-09-14.

## Done when

- При первом `/start` (новый `user_id`) бот показывает Экран 0.1, ждёт нажатия `Начать`.
- После `Начать` показывает Экран 0.2, ждёт перехода к контракту.
- После второго перехода — стандартный Блок 1 (Контракт).
- Повторный `/start` для существующего пользователя онбординг **не** показывает (флаг `onboarded=true` в БД).
- Тексты экранов взяты дословно из `meetings/2026-09-11-заметки-насти-по-схеме.md`.
- Задеплоено на Railway.
